# RoutePin 🌲✈️

RoutePin is a high-end, responsive travel agency and road trip planner web application built for customized Canadian wilderness adventures. Designed with an editorial aesthetic, it features smooth interactive components, cinematic dark-mode visuals, and a fully tailor-made booking experience.

## ✨ Key Features

- **Cinematic Editorial Design**: Styled with a dark theme (`#0A0D14`), serif typography, minimalist iconography, and structured spacing.
- **Interactive Arch Destination Carousel**: Click-to-center gallery layout supporting numerous Canadian destinations with smooth state transitions and reliable image rendering.
- **Statistics & Infographics**: Highlights key metrics including happy customers, comfortable touring vans, and completed tours.
- **Connected Travel Plan Timeline**: A two-row sequential roadmap mapping out all 8 stops across Canada.
- **Interactive Booking / Trip Customizer Modal**: Allows users to select their preferred primary destination, party size, travel dates, and submit a custom itinerary.

## 🛠️ Tech Stack

- **Framework**: Next.js (with Turbopack)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: Vercel
